## 📖 Overview

This folder contains implementations of fundamental **Sorting Algorithms** written in **C++**. Each implementation is built from scratch to understand the logic behind sorting techniques rather than relying on built-in library functions.

---

## 📂 Implemented Algorithms

<details open>
<summary><b>🫧 Bubble Sort</b></summary>

Repeatedly compares adjacent elements and swaps them if they are in the wrong order. Larger elements gradually "bubble" toward the end of the array.

</details>

<details>
<summary><b>📌 Selection Sort</b></summary>

Finds the smallest element from the unsorted portion of the array and places it at its correct position in every iteration.

</details>

<details>
<summary><b>📝 Insertion Sort</b></summary>

Builds the sorted array one element at a time by inserting each new element into its appropriate position.

</details>

<details>
<summary><b>🔀 Merge Sort</b></summary>

Uses the divide-and-conquer approach by recursively splitting the array into smaller parts and merging them back together in sorted order.

</details>

<details>
<summary><b>⚡ Quick Sort</b></summary>

Chooses a pivot element, partitions the array around it, and recursively sorts the resulting subarrays.

</details>
